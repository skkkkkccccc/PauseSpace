# Usability Tasks — PauseSpace mobile prototype (S09)

> **Status: task defined; the peer test is PENDING.** The student facilitates the
> test **without coaching** and decides which finding is actionable. Record **only
> task observations** — no names, no clinical or personal data (follow the S02
> `docs/ResearchProtocol.md` assent, voluntary-participation, stop-rule, and
> data-minimization checklist).

## Prototype under test
- Version: S09 v1 — `design/prototype/index.html`.
- Scope: one scene (exam-room); scene card → detail → player → completion.

## Setup
1. Open `design/prototype/index.html` on a phone or a phone-sized browser window.
2. One consenting peer (read the S02 assent script; participation is voluntary; they may stop at any time).
3. **Give no explanation or coaching** beyond the task wording below.

## The defined task
> "A short, calm scene is about to start. Begin when you're ready, go through it,
> and stop when you're done."

**Success criterion:** the peer completes the path — scene card → Start → Player
→ Finish/Exit — **without explanation** from the student.

## Record only task observations (no personal/clinical data)
- Did the peer complete the path? (yes / no; where they stopped)
- Where they hesitated or looked unsure.
- Any confusing labels or controls.
- Exit discoverability (could they find how to leave?).
- Tap-target / contrast / readability issues on the phone.
